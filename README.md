# Трибуна — демо платформы для родителей юных спортсменов Беларуси

Кликабельный макет закрытой платформы: курсы, семинары и вебинары, личный кабинет родителя и доступ по подписке. Для любого вида спорта.

## Как открыть

Скачайте `index.html` и откройте двойным кликом. Сервер не нужен, шрифты встроены в файл.
Если включён GitHub Pages (Settings → Pages → ветка main, папка root), демо открывается по ссылке на сайт репозитория.

## Что проверить

Вход без пароля, три роли:
- **Родитель с подпиской** — курсы, уроки с вопросом, запись на события, записи вебинаров.
- **Родитель без подписки** — открыт только первый урок каждого курса, остальное закрыто. Дальше выбор тарифа и кнопка «Я оплатил(а)».
- **Организатор** — подтверждает оплату (после этого у родителя открывается доступ), добавляет события, меняет статусы курсов.

Выбор вида спорта на главной меняет табло и список курсов и событий.

## Важно

- Это макет: данные хранятся только в памяти страницы и сбрасываются при обновлении.
- Имена, цены (20, 54 и 180 BYN), реквизиты и тексты уроков вымышленные и подлежат замене.
- Оплата условная. В рабочей версии планируется ручное подтверждение платежа (реквизиты или ЕРИП) с возможностью заменить его онлайн-оплатой.

## Версия 5: лучшее из платформ-аналогов

Добавлено по итогам сравнения с Respect in Sport, NFHS, PCA, TrueSport, TeamSnap и другими:

- **Сертификат родителя** после курса «Родитель на трибуне» (номер вида ТРБ-26-0001). Пройдите три урока — сертификат появится в кабинете.
- **Проверка сертификата клубом** на главной странице, блок «Клубам»: введите ТРБ-26-0002.
- **Код от клуба** на странице входа: LED-2026 открывает базовый курс и сертификат без подписки.
- **Семейный доступ**: до 4 человек в одной подписке (Кабинет).
- **«Обсудите дома»**: два вопроса ребёнку после каждого урока.
- **«Новое в этом месяце»** на главной родителя.
- **Напоминание за день** до события (после записи).
- **Раздел «Клубы»** у организатора: коды, активации, сертификаты, выпуск нового пакета.

Названия клубов, коды, имена экспертов и цены вымышлены.
